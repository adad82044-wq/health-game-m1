# คู่มือการแก้ไขและจัดการโปรเจกต์เกม: "ทางแยกหลังตึก" (สุขศึกษา ม.1)

โปรเจกต์นี้ถูกแยกไฟล์ออกเป็นสัดส่วนอย่างเป็นระเบียบ เพื่อให้คุณสามารถแก้ไขบทพูด เปลี่ยนรูปภาพ หรือปรับแต่งการตั้งค่าได้ง่ายโดยไม่กระทบโค้ดส่วนอื่น

---

## 📁 โครงสร้างโฟลเดอร์และไฟล์ทั้งหมด

```text
เกม/
├── index.html              <-- ดับเบิลคลิกไฟล์นี้เพื่อเปิดเล่นเกมบนเบราว์เซอร์ได้ทันที!
├── image_prompts.txt       <-- รวมคำสั่ง Prompt ภาษาอังกฤษสำหรับนำไปเจนรูป AI ทั้งหมด
├── css/
│   └── style.css           <-- โค้ดตกแต่งหน้าตา กล่องข้อความ ปุ่มตัวเลือก และสีสัน
├── js/
│   ├── config.js           <-- ไฟล์ตั้งค่าระบบ ความเร็วข้อความ และชื่อไฟล์รูปภาพ
│   ├── story.js            <-- ไฟล์บทสนทนา เนื้อเรื่อง และข้อความสรุปบทเรียนทั้งหมด
│   ├── audio.js            <-- ระบบสังเคราะห์เสียงประกอบอัตโนมัติ (Web Audio API)
│   └── engine.js           <-- ตัวขับเคลื่อนเกม (ระบบสลับเพศ, ระบบสุ่ม 1 ใน 3, แสดงผล)
└── assets/                 <-- โฟลเดอร์สำหรับนำรูปที่เจนจาก AI มาวางใส่
    ├── backgrounds/        <-- วางรูปฉากหลัง
    ├── sprites/            <-- วางรูปตัวละคร (บาส, มินต์/อาร์ม, ครูอำนาจ)
    ├── avatars/            <-- วางรูปไอคอนตัวเอก (ชาย/หญิง)
    └── cgs/                <-- วางรูปฉากจบ 4 แบบ
```

---

## 🖼️ วิธีนำรูปที่เจนจาก AI มาใส่ในเกม

เมื่อคุณนำ Prompt จากไฟล์ `image_prompts.txt` ไปเจนรูปได้แล้ว เพียงตั้งชื่อไฟล์ตามตารางด้านล่างแล้วนำมาวางในโฟลเดอร์ `assets/` ตัวเกมจะดึงรูปของคุณมาแสดงแทนภาพกราฟิกจำลองโดยอัตโนมัติทันที:

| หมวดหมู่ | โฟลเดอร์ที่ต้องวาง | ชื่อไฟล์ที่ต้องตั้ง | คำอธิบายรูป |
| :--- | :--- | :--- | :--- |
| **ฉากหลัง 1** | `assets/backgrounds/` | `bg-01.png` | มุมอับหลังอาคารเรียน 3 |
| **ฉากหลัง 2** | `assets/backgrounds/` | `bg-02.png` | ลานเข้าแถวหน้าเสาธงตอนเช้า |
| **ฉากหลัง 3** | `assets/backgrounds/` | `bg-03.png` | ห้องฝ่ายปกครอง |
| **ตัวละคร 1** | `assets/sprites/` | `sprite-01-bas.png` | บาส (ยื่นบุหรี่ไฟฟ้า) |
| **ตัวละคร 2** | `assets/sprites/` | `sprite-02-friends.png` | มินต์และอาร์ม ยืนพิงกำแพง |
| **ตัวละคร 3** | `assets/sprites/` | `sprite-03-teacher.png` | ครูอำนาจ ฝ่ายปกครอง |
| **อวาตาร์ชาย** | `assets/avatars/` | `avatar-m.png` | นนท์ (นักเรียนชาย ม.1) |
| **อวาตาร์หญิง** | `assets/avatars/` | `avatar-f.png` | เนย (นักเรียนหญิง ม.1) |
| **ฉากจบดี** | `assets/cgs/` | `cg-good.png` | รอดพ้นหน้าเสาธง |
| **ฉากจบร้าย A** | `assets/cgs/` | `cg-bad-a.png` | ห้องปกครองและแม่ร้องไห้ |
| **ฉากจบร้าย B** | `assets/cgs/` | `cg-bad-b.png` | ทรุดข้างสนาม หายใจไม่ออก |
| **ฉากจบร้าย C** | `assets/cgs/` | `cg-bad-c.png` | กระเป๋าตังค์แห้ง ถูกเพื่อนเมิน |

> **ทิป:** หากรูปของคุณเป็นนามสกุล `.jpg` หรือ `.webp` สามารถเข้าไปแก้ชื่อนามสกุลไฟล์ได้ที่ไฟล์ `js/config.js` ได้เลย และเมื่อใส่รูปครบแล้ว สามารถซ่อนป้ายบอกชื่อไฟล์มุมบนซ้ายได้โดยเปลี่ยน `showAssetDebugHint: false` ใน `js/config.js`

## ✏️ วิธีแก้ไขบทพูดและตัวเลือก (`js/story.js`)

เปิดไฟล์ `js/story.js` ด้วย Notepad หรือ VS Code:
- แก้ไขข้อความหลังคำว่า `text: "..."` ได้ตามต้องการ
- หากใส่คำว่า `{name}` ในประโยค ระบบจะเปลี่ยนเป็นชื่อที่ผู้เล่นพิมพ์ในหน้าแรกให้อัตโนมัติ
